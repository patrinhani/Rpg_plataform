C.A.O.S. VTT — INÍCIO RÁPIDO

1. Extraia TODO o conteúdo do ZIP para uma pasta comum.
2. Para jogar pela internet, abra "Iniciar C.A.O.S. VTT Online.cmd".
   Se for abrir o VTT pelo sistema hospedado na Vercel, edite antes ORIGEM-WEB.txt e coloque
   apenas a origem HTTPS do site, por exemplo: https://seu-projeto.vercel.app
3. Para usar apenas neste computador, abra "Iniciar C.A.O.S. VTT.cmd".
4. Aguarde o navegador abrir e copie o Host token mostrado na janela preta.
   O fluxo mais simples usa a página aberta pelo próprio endereço trycloudflare. ORIGEM-WEB.txt
   só é necessário para abrir o VTT por outro site, como o botão da Mesa na Vercel. Nesse caso,
   cole também o endereço https://*.trycloudflare.com exibido em "URL do servidor".
5. Crie a sala, conecte como Mestre e use "Copiar link completo para o jogador".
6. Compartilhe SOMENTE esse link de jogador — nunca o host token ou convite de Mestre.

Mantenha CAOS-VTT.exe e _internal juntos. Mantenha também campaigns e cloudflared.exe quando
essas pastas/arquivos estiverem presentes na variante recebida.
Não execute o programa dentro do ZIP e não feche a janela preta durante a sessão.

As rolagens continuam sendo feitas com dados físicos. Fechar o programa encerra o servidor e o
túnel, mas a sala continua salva em data\caos-vtt-state.sqlite3. Ao retomar a Mesa, o estado é
recuperado e novos convites são gerados; links antigos deixam de funcionar.

O fog of war começa ligado e totalmente fechado. Com ele ligado, o servidor compõe mapa, objetos
de cenário e overlays antes de enviar a imagem ao jogador; tokens em áreas ocultas não aparecem.
Para transportar ou fazer backup das sessões, copie também a pasta data com o programa fechado.

Se o Windows mostrar um alerta, não desative o antivírus. Confira o SHA-256 do ZIP e consulte
README-PORTABLE.md para diagnóstico, modo local e detalhes de segurança.
